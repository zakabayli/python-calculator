# 🧮 Python Calculator

A simple command-line calculator written in Python. It supports basic operations like addition, subtraction, multiplication, and division. You can keep calculating with the result or start over.

## 🚀 Features

- Add, subtract, multiply, divide
- Chained calculations (use result as next input)
- Simple, clear terminal interface
- ASCII art welcome screen
- Written in plain Python, no frameworks

## 🧰 Requirements

- Python 3.x
- `art` library

🎯 Why this project?
I'm currently learning Python and building mini projects to practice key concepts like functions, loops, and input/output.
